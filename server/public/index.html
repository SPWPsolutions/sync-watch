Get Party Sync for Netflix and Crunchyroll

Netflix and Crunchyroll play on their own sites. The Party Sync extension keeps everyone in sync there. Works in Chrome, Edge and Brave.

Download extension (.zip)

How to install (it isn't on the Chrome Web Store)

  1. Unzip the downloaded file. You get a party-sync-… folder.
  2. Open chrome://extensions in a new tab.
  3. Turn on Developer mode (top right).
  4. Click Load unpacked and pick the unzipped party-sync-… folder.
  5. Turn off other watch-party extensions such as Teleparty. Both run on Netflix and will get in each other's way.
